# My TypeScript Project

## Overview
This project is a TypeScript application that provides default program values based on the input size. It includes utility functions, type definitions, and unit tests to ensure functionality.

## Project Structure
```
my-typescript-project
├── src
│   ├── index.ts          # Entry point of the application
│   ├── utils
│   │   └── programDefaults.ts  # Utility functions for default program values
│   └── types
│       └── index.ts      # Type definitions and interfaces
├── tests
│   └── programDefaults.test.ts  # Unit tests for utility functions
├── package.json          # Project metadata and dependencies
├── tsconfig.json         # TypeScript configuration
└── README.md             # Project documentation
```

## Setup Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd my-typescript-project
   ```
3. Install dependencies:
   ```
   npm install
   ```

## Usage
To run the application, execute the following command:
```
npm start
```

## Running Tests
To run the unit tests, use:
```
npm test
```
